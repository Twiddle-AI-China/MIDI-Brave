    SOURCE · 真实参考

    Held-out Serum 实际渲染音频，是比较目标，不经过模型。

    DYNAMIC · 动态轨迹重建

    Source 提取音高归一化 96D 特征，经 Encoder 得到随时间变化的 128D 轨迹，再用相同 MIDI 解码；检验 Encoder+Decoder 的重建能力。

    STATIC · 静态轨迹消融

    把 Dynamic 轨迹沿时间取均值并复制到所有帧，再用相同 Decoder/MIDI 合成；用于判断时间变化轨迹是否真的有贡献，不是另一套模型。

    FLOW · 完整轨迹预测

    不读取 Source 轨迹。Flow 根据 Atlas 锚点、8D 坐标、生命周期与历史生成 128D 音色轨迹，随后 Decoder 注入相同 MIDI；检验独立轨迹预测能力。

    指标覆盖 3 个 held-out preset × MIDI 36–71 共 108 组；页面展示每个 preset 的六个代表音高，共 18 组。播放器切换模式时保持当前时间，请使用耳机并统一音量。
